Privacy Policy

Last updated: September 10, 2026

JARVIS YouTube Publisher is a private productivity application used by its owner to manage YouTube content, metadata, analytics and publishing workflows.

Google and YouTube data

The application accesses Google and YouTube data only after the user explicitly grants permission through Google OAuth.

Data may include YouTube channel information, video metadata, analytics data, and Google Drive files required for the publishing workflow.

How data is used

Google user data is used only to provide the requested YouTube management, analytics and publishing functionality.

Google user data is not sold, rented, or shared with advertisers.

Data storage

Authentication credentials are stored securely using Google Cloud Secret Manager. Workflow files may be stored in the user's Google Drive.

Revoking access

The user can revoke the application's access at any time from their Google Account security and permissions settings.

Contact

For questions about this privacy policy, contact the developer using the support email listed on the Google OAuth consent screen.
